Teno MVP 候选：Android 0.7.0 / 14，Web 0.2.0 / 5
设计依据：用户提供的 16 张图片切片和 20261109-v1 的 34 状态原型；旧 Plaud 页面分类只作为功能回归历史。

已实现
暖白/鼠尾草绿/深绿共享主题、深色适配、字体与统一卡片/弹层；移动端首页/助手/设置三项导航、资料库与导入快捷入口；桌面侧栏、受限正文宽度、侧边主题目录和居中弹窗。
首页简报只读取已有最新笔记；缺少笔记不生成假内容。原生录音卡与手机录音入口保留，Web 省略硬件入口。
共用 Notes v2/旧稿/手写稿/历史版本：来源与笔记双页签、概览/全文、真实目录和来源定位、版本、分享中心及导出；模板中的原文入口只打开已有转写。
中英文/跟随系统，登录前和设置可切换，设备级持久化。用户正文、姓名、文件名与 Ask 历史不翻译；Automatic、摘要语言和账号偏好保持独立。
原生通知、密钥与分享弹窗使用共享词表；切换不销毁原生会话。中文字体本地打包，Web 只下载压缩字体，保留许可证。

自动化与视觉分开
362 项 Flutter、33 项浏览器 runtime 契约通过；Android 同签名 0.6.2 覆盖升级 74 项、最终原生回归 68 项、冷启动通过。后端 1.5.1 只读 HTTPS 255 项通过，本轮未重跑未修改后端的 336 项单元测试，也未产生新的 ASR/模型调用。
87 个回归状态 × 浅/深/360dp 1.5 字号 = 261 张；另 220 张双语与手机、768、1280、1440、横屏的实际 Flutter 导航截图。双语截图覆盖 11 个核心页面，其他状态的三模式截图为英文；不能声称 34 状态均完成双语逐像素验收。
481 张均为 Flutter 合成资料截图；verification/v0.7.0 的系统文件/照片/键盘为 Android API35 模拟器实截图。浏览器实测另存私有证据，含真实账号内容，不进入公开源码。
没有全页面 <=4dp 测量通过结论。新图片风格已落地，设备复杂状态沿用真实功能层级及通用设备图标；没有把圆盘概念图当作 JWD 实物。

保留差异与边界
模板内容沿用 Teno 自有内容，所有旧模板仍可访问；没有仅为四张推荐卡删模板。查找设备与个人思维导图导出本轮省略。
原生系统栏/权限/文件选择器由 Android 管理；Web 不增加蓝牙、麦克风或手机日历。分享继续使用真实固定版本、内容范围、有效期及撤销。
首次读取仍需联网；已有录音缓存沿用账号隔离、失效与后台更新规则，不承诺离线 App。首页简报没有新增生成任务。

待实机与发布门槛
真实 iPhone Safari、Magic4 Pro/JWD 尚无设备验收。当前是可安装/可浏览候选，不提升 Android 0.6.2 和 iOS 0.5.0 基线，不切换正式 /app/，不合并 main、不发商店、不交付 iOS。
可在专用候选入口检查新 UI。按计划完成实机链路后，再分别提升 Web 静态入口和 Android 交付基线。已装高 versionCode 的设备不要卸载清数据降级，回退应构建更高 code 的兼容包。
