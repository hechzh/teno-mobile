Teno 0.2.1 — JWD 录音卡基础测试
交付日期：2026-10-31（北京时间）
适配目标：Magic4 Pro / Magic UI 6.0 / Android 12。

安装
下载并在手机安装 dist/Teno-0.2.1-jwd-test.apk。
包名仍为 com.teno.app，沿用 0.1.0 内测 release 签名，可以覆盖升级。
如果提示签名冲突，请反馈提示，不要卸载已有版本或清除数据。
App 支持 ARM64 / ARMv7，最低 Android 8.0。厂商原始解码库用于本次内测。

第一次测试（建议录 10–30 秒）
1. 先登录 Teno 原有内测账号 android_test 或 collaborator_test。
   密码沿用原账号；本机私有账号文件：C:/Users/lexia/.ssh/pocket-test-accounts.json。
   APK 不包含账号密码。服务器默认地址：https://54-214-180-183.sslip.io。
2. 首页点击“JWD 录音卡 · 连接、录音与上传”，允许“附近的设备”权限。
3. 打开录音卡，点击“扫描附近设备”。先点“检查 JWD 服务”，看到
   “已核实 JWD 服务与录音通道”后，再点“连接录音卡”。
   广播含 JWD 服务、名称符合 SDK 示例都只是候选线索，不等于已经确认设备。
   没找到时，点击“找不到录音卡？尝试兼容扫描”（采用厂商 Demo 的设备发现）。
   新型号名称可展开“其他未识别设备”后检查；不要随意绑定陌生设备。
4. 全新、未绑定的设备选择“首次绑定”，App 自动生成独立密钥并在手机加密保存。
   已被其他 App 绑定的设备选择“输入原密钥”；使用原来的 16 位字母/数字密钥。
   看到“授权成功”后再录音。16 位设备密钥在手机输入，无需在录音卡输入。
   密钥不匹配不会自动重置或格式化设备。
5. 点击“开始设备录音”，说一段中文，再点“停止并保存设备录音”。
   也可用录音卡物理按键录音；连接后读取设备实际状态。
6. 点“刷新状态和录音文件夹”，打开日期文件夹，选录音“传到手机”。
   等待字节长度、结束标志、设备 CRC32 校验及音频解码。
   如果旧固件不提供 CRC32，页面会明确显示“已校验文件长度”。
7. 在“已传到这台手机”中试听，确认声音正常，然后点“上传到云端”。
8. 手机使用正常 Wi-Fi 或移动网络即可上传，无需电脑、USB 或 SSH 隧道。
   返回资料库查看转写及摘要；处理需等待云端任务完成，可点“刷新录音库”。

系统 PIN 提示与设备识别
- 手机显示数字，要求在另一台设备输入，是系统蓝牙配对流程。
  它不是 Teno 的 16 位设备密钥。请先取消；厂商给定协议/SDK 没有说明此 PIN。
- SDK 示例名称包括 VTR、H10、H11、HQ10、HQ11、HQ-10_P、HQ-11_P、Dex_ 等前缀。
  不能仅根据名称判断设备身份，最终应检查 JWD 服务及三个录音特征。
- JWD 服务 UUID：001120a0-2233-4455-6677-889912345678。
- 用户反馈 SGMf91a73 弹出对端输入数字提示；该名称不在 SDK 示例清单，
  目前没有证据确认它是用户的录音卡。应先取消，再对比录音卡关机/开机扫描结果。
  做关机对比前先停止录音。不要通过重置、格式化或猜测 PIN 试错。
- 新版诊断记录 PIN 请求发生阶段及是否核实 JWD 服务，不记录显示出的 PIN 数字。
  如果已核实 JWD 服务仍弹 PIN，请导出诊断，核对具体硬件型号/固件配对要求。

未登录时
登录页有“JWD 设备连接测试（无需登录）”，可离线连接、控制录音和浏览设备文件。
下载到手机及云端上传需要先登录，以便按账号保存本地文件。

失败重试与反馈
- 蓝牙断连、数据不完整或 CRC32 错误时，不生成可上传文件；重新连接后完整重传。
- 已保存到手机的文件，网络上传失败后仍保留；恢复网络再点“上传到云端”。
- 重复下载同一设备、目录、文件名、内容的文件复用 client_id，避免重复上传记录。
- App 不删除录音卡原文件，不提供格式化、解绑或 OTA 按钮。
- 在“设备密钥与备份”查看并私下保存密钥；卸载或清除 App 数据会丢失本机密钥。
- 遇到问题，点击“导出测试诊断”，保存 JSON，并反馈卡片蓝牙名、出错步骤、屏幕提示。
  诊断文件包含版本、手机型号和流程事件，不包含设备密钥、登录令牌或录音正文。
- 首次测试保持 App 在前台；基础测试通过后再测锁屏、后台和断网。
  如锁屏会断开，检查系统对 Teno 的后台活动/电池管理限制，再对照重试。

本次范围
已接入：BLE 扫描、独立密钥授权、设备开始/停止录音、状态/电量/固件读取、
文件夹/文件列表、BLE 文件传输、长度/CRC32 校验、SDK Opus 解码、
本地播放、HTTPS 上传、上传失败重试、测试诊断。
本次没有接入：Wi-Fi 快传、断点续传、设备解绑/格式化、OTA、iOS、实时字幕。
当前后端限制：单段最多 60 分钟、上传文件不超过 100 MiB；先测短录音。
