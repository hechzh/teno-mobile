Teno 0.5.0 双平台首版内测记录
日期：2026-11-05

本轮交付
按 20261104 的逐页基准实现 Flutter 共享页面，Android Java / iOS Swift 承担原生运行服务。
产品统一 Teno / Ask Teno、英文界面。Android 包名 com.teno.app，versionCode 10。
Android 唯一宿主仍为 app/，共享模块 shared-ui/，新增 iOS 宿主 ios/，都位于 pocket/android。
现有网页、共享后端、数据库和历史数据未迁移或部署；没有新增后端业务接口。

文件入口
- design-baseline/index.html：37 个独立页面/状态，可切换 Android / iOS 样式及当前参考。
- design-baseline/pages.json：33 页设计依据、适配范围、证据缺口和图片 SHA256。
- ARCHITECTURE.txt：架构、组件边界、存储兼容、账号切换与录音/上传状态。
- dist/Teno-0.5.0.apk：本机沿用原证书签名的 Android 内测包。
- dist/Teno-0.5.0-unsigned.ipa：macOS CI 生成的 iOS Release 包，需本地重签。
- dist/Teno-0.5.0-source.zip：Android、Flutter、iOS 及授权 SDK 源码包。
- dist/Teno-0.5.0-release-manifest.json：产物哈希、签名与验证边界。
- ios/INSTALL.txt：Windows / AltStore Classic 安装、刷新及实机核对步骤。

首版功能
登录；JWD 为主、手机为次的录音入口；暂停、继续、停止确认；文字笔记/时间高亮；
可展开的实时字幕；完整文件校验和自动本机保存；音频导入、持久化上传与失败重试；
资料库、文件夹、搜索、播放/倍速；分段转写编辑；摘要编辑、模板及版本；Ask 与历史；
设置、系统分享导出、回收站。识别固定 Automatic。

Work、Tasks、Routines、Skills、Connectors、照片、独立新笔记、公开链接、团队知识库、
任务认领审核及声纹管理不作为新 APK / iOS 入口。原服务器数据和网页仍保留。
本期没有批量文件管理、拖拽排序、日期/说话人组合筛选、日历/Upcoming 或社区模板市场；
这些差异在各页对照中列出，不能称作原版所有细节已完整复刻。

Android 安装
使用 dist/Teno-0.5.0.apk 覆盖已有原签名 Teno。不要先卸载、清除数据或改用 CI debug APK。
JWD 已绑定设备继续使用原密钥。连接中断时设备可能仍在录音，先重新连接确认状态。
录音和完整同步期间需完成操作后再切换账号；上传期间切换账号会暂停原账号任务并保留文件。

iPhone 安装
按 ios/INSTALL.txt 通过 AltStore Classic 本地重签未签名 IPA，Apple 账号不进入 CI。
免费签名需要约每 7 天刷新。保留同一账号和安装标识，避免卸载造成本机文件丢失。
未向 App Store / TestFlight 自动提交，也未将此次改动合并至 main 或替换网页后端。
