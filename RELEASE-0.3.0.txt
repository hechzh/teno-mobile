Teno 0.3.0 · Android 内测版
2026-11-01

安装 dist/Teno-0.3.0.apk，直接覆盖原来的 Teno，不需要卸载。
包名仍为 com.teno.app，沿用原 release 签名。测试账号沿用此前账号；密码不在安装包内。

本次更新
• 根据英文 V2 设计重做原生界面：Library、Ask、Tasks、Account，增加个人/团队工作区切换。
• 界面文案全部改为英文，采用浅色背景、深色按钮和圆角卡片；原始录音文字保留其语言。
• 手机录音接入 Azure Speech SDK 实时桥接，可显示临时和确认字幕。暂停、结束、网络中断会显示实际状态。
• 录音先保存在手机，Stop and save 后选择 Save and continue 上传。断网或转写失败时保留音频。
• 完整实时转写经音频哈希校验后复用；有缺口时重新转写完整音频。上传重试沿用同一录音编号。
• 录音卡页面分为连接、录音、导入、设置与帮助；增加 Opus 实时字幕预览，保留完整文件校验和密钥备份。
• 接入团队会议、群聊文本导入、身份核对、发布、知识库、来源问答、任务建议/去重、认领/进度/提交/审核。
• 增加摘要编辑版本与消息草稿；消息只能由用户手动分享。

建议先测试
1. Library → Start recording，选择 Phone microphone、正确的 Transcription language，启用 Live transcription。
2. 说话约 20 秒，查看字幕，暂停并继续，再 Stop and save → Save and continue。
3. 打开录音，试听并查看 Summary / Transcript。
4. Recorder device → Scan for devices → Check service → Connect，确认录音卡后测试录音与导入。
5. 录音卡停止必须收到设备确认；再到 Device recordings 导入完整文件和上传。

语音识别语言与界面语言独立，可选择 Chinese (Mandarin) 或 English (US)。首次使用新版时，生成内容默认英文；Account → Preferences 可调整摘要语言。

测试范围
后端 53 项检查、Android 29 项链路检查、11 项界面/离线补充检查、22 项协议检查通过。真实 Azure 即时识别、暂停超过 30 秒、转写复用、重传去重、摘要生成及团队审核均已验证；release 签名及从 0.2.1 覆盖安装通过。
硬件音频测试使用合成 Opus，手机采集测试在 Android 15 模拟器进行。Magic4 Pro / Android 12、录音卡实际 BLE 音频、长录音及锁屏省电仍待实机验收。

当前限制
• 手机 PCM 录音最长约 54 分钟；音频导入最多 60 分钟 / 100 MiB。
• 当前 Azure F0 仅允许一个识别会话；忙碌时本机继续录音，稍后补转写。
• 录音卡实时接入目前支持 SDK 所示的固定 80 字节 Opus 格式；其他格式会明确提示，完整录音仍留在设备上。
• 录音卡实时字幕是预览，停止后仍需导入经过完整性校验的文件；蓝牙断开不代表设备已停止录音。
• Wi-Fi 快传、OTA、iOS、付费订阅及外部连接器仍未开放。

设备帮助保留了“三次快按，红灯闪烁后长按约五秒”的重置说明，同时说明该操作会格式化并解除绑定。App 不会自动重置设备。
