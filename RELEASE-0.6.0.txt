使用变化
Cloud processing 按账号生效：设置键缺失时开启，已有明确 false 保留；不再受首次录音设置阻挡。
新录音、导入音视频先完整保存，再自动排队上传、转写和生成笔记；遵守 Wi-Fi 限制。
文档/图片上传后异步提取或本地 OCR，保存来源和页码。失败保留本机原件并显示原因。
历史未申请上传的文件不自动补传，可以手动或批量处理。
导入入口：首页“＋”→ Import files → From Files / From Photos / From other apps；支持多文件。
其他 App 的系统分享可接收音视频、文档或图片；未登录时暂存，登录后确认接受到当前账号。

个人核心
首页 Upcoming、日期分组、排序和底部 Ask；侧栏、系统目录、嵌套文件夹及选中状态。
手机/JWD 录音、照片、文字和时间高亮；本机副本、失败重试、处理状态及通知。
资料库跨录音、笔记、文档、图片、文件夹的分页/排序/搜索，搜索历史、高亮和时间/页码定位。
批量移动、删除、恢复及拖拽归档；裁剪和合并异步生成新录音，原文件保留。
真实波形、章节、播放跟随、跳转、原稿/编辑稿/清理稿、查找替换及修订。
Azure Fast 说话人分离；命名只绑定当前录音和转写版本，重新转写后需要重新核对。
New note、多笔记、封面、独立编辑与版本、旧摘要映射、独立文字笔记和 Ask 回答保存。
模板分类、搜索、收藏、最近使用和自建编辑；推荐模板为 Teno 自有内容。
Chat 支持录音、笔记、文档和文件夹上下文、历史及引用定位；语音问题先显示可编辑文字。
手机系统日历、手动/ICS 导入、Upcoming 及录音关联；无第三方 OAuth。
主题、通知、缓存管理和默认关闭的系统生物识别/锁屏凭据应用锁。
按音频/转写/笔记组织 MP3/WAV、TXT/MD、SRT、DOCX、PDF 和 JSON 导出及相关选项。
链接由用户显式创建，默认仅摘要、7 天有效、不附音频；固定内容版本，可撤销，来源删除后失效。

兼容和限制
音视频导入上限 120 分钟 / 250 MiB；图片 20 MB，办公文档 15 MB，文本 2 MB。
支持 MP3/M4A/WAV/AAC/FLAC/OGG/MP4/MOV/3GP/WEBM，按内容验证和解码，不只检查后缀。
文档支持 PDF、DOC/DOCX、PPTX、TXT、MD、MSG、PNG/JPG；本地 LibreOffice/Poppler/Tesseract。
文档提取保护为 200 页、10 分钟、一百万字符，图片 25MP，Office ZIP 展开 100MB；超限明确报错。
手机 PCM 录音保留既有约 54 分钟上限，JWD 约 60 分钟；不把导入上限当成手机录音上限。
语音提问单次最多 60 秒；识别后由用户确认发送。OCR 主要针对英文和简体中文。
本人声纹、Agent、Work、Tasks、Skills、Routines、Connectors、会员支付、团队和第三方登录后续实现。
原团队网页、自动化、团队生成 Prompt 和旧业务接口保留；个人生成流程独立，旧客户端未传新参数时沿用旧行为。
