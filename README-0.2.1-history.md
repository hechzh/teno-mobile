# Teno Android 0.2.1 JWD 基础测试版

交付日期：2026-10-31（北京时间）。应用名称 **Teno**，包名 `com.teno.app`。这是独立实现的原生 Android 客户端，使用已有 FastAPI 后端；未复制 Pocket 逆向代码。JWD SDK 和协议原文件保持原样。

## 0.2.1 设备识别修正

0.2.0 扫描列表混合显示所有有名称的 BLE 设备，未展示识别证据，容易选错。用户报告 SGMf91a73 在 Teno 连接时触发系统显示数字、要求对端输入的配对弹窗；设备身份仍未确认，不能将此视为实际 JWD 已连接。

0.2.1 优先显示已核实服务、广播服务匹配、SDK 名称候选三类条目，其他设备默认折叠。未核实设备只能先做只读服务检查，不发送绑定指令、不生成密钥；查到 JWD 服务与三条录音特征后才开放连接入口。补充厂商 Demo 相同的系统设备发现作为兼容扫描，记录系统配对请求及触发阶段，不读取/填写 PIN 或自动确认配对。

本次 22 项协议/名称检查、15 项模拟器设备选择/探测/兼容扫描检查通过，报告见 `verification/jwd-0.2.1/`。0.2.0 真实上传验证是历史证据，未在本次重复运行；录音卡实机身份和 PIN 原因仍需用户诊断。

## JWD 录音卡测试

本次目标设备是用户的 Magic4 Pro / Magic UI 6.0 / Android 12。详细步骤见 [JWD-测试指南.txt](JWD-测试指南.txt)。首页点击“JWD 录音卡 · 连接、录音与上传”：扫描 → 检查 JWD 服务 → 连接并独立密钥授权 → 设备录音/停止 → 读取文件夹 → BLE 传到手机 → 校验/解码 → 试听 → 上传。登录页也提供无需登录的设备连接测试入口；下载与上传需登录。

协议自动检查 17 项、模拟器厂商解码/播放/真实 HTTPS 后端链路 15 项、模拟器权限与扫描生命周期 4 项通过。新版本报告位于 `verification/jwd-0.2.0/`。使用的是合成 Opus 音频，不是录音卡实际采集；真实 JWD BLE、Magic4 Pro、中文录音、锁屏与长文件仍待用户测试。Wi-Fi 快传、断点续传、OTA 和 iOS 不属于本次交付。

## 安装与首次使用

安装 `dist/Teno-0.2.1-jwd-test.apk`。沿用原包名与 release 签名，支持从 0.1.0 覆盖升级。最低 Android 8.0（API 26），当前以 Android 15（API 35）模拟器验收。APK 是独立签名、非 debuggable 的内测 release 构建；首次安装需要允许所用文件管理器/浏览器安装应用。

服务器默认地址：**https://54-214-180-183.sslip.io**。HTTPS 证书已签发并验证；服务器自动续期。手机使用 Wi-Fi 或移动网络即可，不依赖电脑、USB、ADB 或 GMS。

使用此前交付的 `android_test` 或 `collaborator_test` 账号。密码在本机 `C:/Users/lexia/.ssh/pocket-test-accounts.json`，没有写入 APK 或源码。安装后填写账号密码，允许麦克风权限；通知权限用于录音、上传与本地提醒。

1. 首页点击“开始录音”，填写标题、转写语言及可选背景笔记。
2. 录音期间可暂停、继续；可锁屏或切换到其他应用，通知栏显示采集状态。
3. 点击“停止并生成摘要”：先保存 M4A，再自动上传。失败时保留本地录音，点击“上传处理”重试。
4. 资料库显示录音。点击详情查看转写进度、摘要、原文、待办和导图。云端任务在退出 App 后继续执行。
5. 点击“围绕这条提问”，或在资料库勾选多条录音，进行带原文时间引用的问答。

转写语言须与音频一致；英文样本选择 `English / en-US`。遇到无语音、识别错误或摘要歧义，保留原音核对，可以编辑文本后重新总结。当前摘要与问答默认中文。

## 0.1.0 原有软件链路验收证据（历史）

`verification/acceptance-report.json` 保存 Android 模拟器测试结果；`home.png`、`recording.png`、`summary.png` 为实际运行截图。测试分别检查：

- 公网 HTTPS 证书、登录、Keystore 会话持久化。
- Android 麦克风采集、暂停/继续、M4A 可解析、停止后自动上传。
- 通过 Android 上传服务发送完整英文会议音频，Azure 返回文本，DeepSeek 自动返回摘要。
- 问答引用、分类筛选、待办完成、Markdown 导出、结果在 Activity 中渲染。

模拟器麦克风用于验证采集与生命周期；可识别语音使用另一个已知内容的合成 WAV 样本。不能据此宣称已验证实体手机麦克风识别质量、真实录音卡、长录音或所有 Android 厂商后台策略。验收数据保留在内测账号中，名称以“Teno … 验收”标识。

## 源码与构建

原生 Java + Android framework，无 Flutter/WebView、无第三方 AI 密钥、无 GMS SDK。Gradle 8.11.1、AGP 8.9.3、JDK 21，compile/target SDK 35，min SDK 26。

```powershell
$env:JAVA_HOME='C:/Program Files/Android/Android Studio/jbr'
./gradlew.bat :app:assembleDebug :app:lintDebug
./gradlew.bat :app:assembleRelease
```

`local.properties` 指向本机 Android SDK，不纳入源码版本管理。release 签名配置读取 `~/.android/teno-signing.properties`，私钥也在 `~/.android/`；不要把这些私有文件加入仓库或发送给非授权方。将来升级同包名安装包必须保留同一签名。

| 文件 | 作用 |
|---|---|
| `MainActivity.java` | 页面、录音库、详情、问答、任务/日程/记忆、导入导出 |
| `RecorderService.java` | Android 前台麦克风录音与本地持久化 |
| `TransferService.java` | 前台上传、上传进度、幂等 client_id、失败保存 |
| `Api.java` | HTTPS API、JWT 自动刷新、multipart 上传 |
| `Store.java` | Keystore 加密会话、账号作用域、本地录音元数据 |
| `MindMapView.java` | 树形导图与 PNG 输出 |
| `ReminderReceiver.java` | 当前账号的本地提醒通知 |
| `SmokeInstrumentation.java` | 显式运行的 Android 真实服务验收，不进入主 APK |

## JWD 实现与测试入口

| 文件 | 作用 |
|---|---|
| `JwdActivity.java` | 独立设备测试页面、权限、密钥备份、试听/上传、诊断导出 |
| `JwdBle.java` | 串行 GATT 订阅、MTU、写入队列、断连和超时 |
| `JwdProtocol.java` | 协议编码、输入验证、长度/结束标记/CRC32 接收门槛 |
| `JwdService.java` | connectedDevice 前台服务、设备状态、列表、传输与 draft 登记 |
| `JwdAudio.java` | 内容识别、厂商 Opus 解码、WAV 校验与幂等本地文件 |
| `VENDOR-JWD.md` | 原厂来源、复制文件、SDK 示例修正点与平台依据 |

不执行设备格式化、解绑、删除文件或 OTA。旧固件未返回 CRC32 时仅显示长度校验；坏 CRC、超长/短文件或坏 Opus 帧不得上传。已保存的本地文件沿用 `TransferService` 上传，失败保留副本。成功传输后也不删除设备原件。

开发验证构建可用 `-PverificationAppId=com.teno.app.jwdverification -PtestRunner=com.teno.app.JwdInstrumentation`，测试 APK 不进入用户安装包。`JwdUiInstrumentation` 单独验证权限与扫描生命周期。最终 release 不传这些属性，包名仍为 `com.teno.app`。

原生库仅包含厂商 ARM64/ARMv7 二进制，未声明所有 Android 新设备兼容。设备密钥与 JWT 使用 Keystore 加密，应用备份和设备数据迁移排除私有数据；卸载前应在设备页面备份绑定密钥。
