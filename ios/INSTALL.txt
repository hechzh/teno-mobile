Teno 0.5.0 iPhone 内测安装（Windows / AltStore Classic）
更新：2026-11-05

交付文件：../dist/Teno-0.5.0-unsigned.ipa
这是 Release 设备构建，最低 iOS 15。unsigned 表示尚未使用你的 Apple 账号重签，
不能直接在 iPhone 点开安装。CI 不保存 Apple 账号，也没有上传 App Store/TestFlight。
此说明是安装步骤；实际 iPhone / AltStore 安装结果仍需记录，不以云端构建替代。

1. 按 AltStore 官方 Windows 指南安装 AltServer 及其要求的 Apple iTunes/iCloud。
   官方建议使用 Apple 直接提供的版本，具体链接和兼容说明以该指南为准。
   https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
2. 连接并解锁 iPhone，确认信任这台电脑，在 iTunes 开启 Wi-Fi 同步。
3. 从 Windows 托盘的 AltServer 选择 Install AltStore，选择你的 iPhone。
   Apple 账号由你在 AltServer 界面中输入，不交给源码、GitHub Actions 或本项目。
4. 按系统提示信任开发者。iOS 16 及以上还需在“隐私与安全性”启用开发者模式。
5. 将 IPA 保存到 iPhone“文件”，在 AltStore 的 My Apps 中通过加号选择 IPA 完成重签安装。
   My Apps、刷新及名额说明：https://faq.altstore.io/altstore-classic/your-altstore
6. 打开 Teno，使用现有 Teno 账号登录。首次手机录音允许麦克风；首次设备操作允许蓝牙。
   首次连接已绑定的 JWD 时输入原设备密钥，不要为了连接执行设备重置/格式化。
7. 免费签名大约 7 天到期。在到期前，通过 AltStore 刷新，电脑上的 AltServer 需可达。
   保持同一 Apple 账号与安装标识。更新 IPA 时覆盖安装，不要先删除 Teno。

免费个人账号的 App ID / 设备 / App 数量及 7 天期限见 Apple 官方说明：
https://developer.apple.com/help/account/basics/about-your-developer-account/
Apple 当前说明为每设备最多 3 个 App，配置描述文件自签发起 7 天有效。
AltStore 本身占用可安装 App 名额；实际可用名额以安装界面为准。

首次实机验收
- 登录、退出、重新登录：原账号本机文件保留，新账号不显示原账号录音。
- 手机录音：权限拒绝/允许、暂停恢复、锁屏、来电、耳机断开、停止后本机播放。
- JWD：服务识别、原密钥授权、开始/暂停/继续/停止回调、断连再连、完整文件校验。
- 断网保存、恢复网络上传、后台上传、同 client_id 重试、处理后的转写/摘要/Ask。
- 系统导入/分享、键盘安全区、返回操作、不同文字大小与设备尺寸。
